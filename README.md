# finanz-steuer-coach-claude-skill
Finanz- und Steuer-Coach für Deutschland: bei Fragen zu Steuern, Arbeitgeber-Benefits, Altersvorsorge, ETFs, Versicherungen, Fixkosten senken, Hauskauf/Immobilie, Fördermitteln (KfW, BAFA, E-Auto, PV) oder Auswanderung – fragt gezielt nach, gibt belegte Vorschläge und erstellt einen Umsetzungsplan als Dokument mit Quellen.
